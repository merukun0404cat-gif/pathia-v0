# Pathia v0.1（パシア）

院内クリニカルパスの統合・分析・委員会運営をイメージした **GitHub Pages向け試作版** です。

## 起動方法

1. このフォルダをGitHubリポジトリへアップロード
2. Settings → Pages → Deploy from a branch
3. `main` / `/ (root)` を選択
4. 発行されたURLを開く

ローカルでは `index.html` を直接開いても多くの機能を確認できます。

## デモログイン

パスワードは全アカウント共通で `pathia0` です。

- `office` : 事務局管理者
- `ward5` : 5階病棟パス係
- `ward6` : 6階病棟パス係
- `committee` : 委員会構成員
- `surgery` : 外科パス責任者
- `viewer` : 閲覧者

- 事務局の部署別進捗確認
- 月次公開イメージ

- 医師判断を院内知識として履歴登録
- パス委員会・会議資料・議事録CSV取込イメージ
- スケジュール登録・対象者通知のモック
- 委員・権限管理
- 使い方・用語集・FAQ
- 委員会資料の印刷／PDF保存用画面

## 重要：このv0では実患者情報を入れないでください

この版は静的なGitHub Pagesで動くデモです。入力データはブラウザの `localStorage` に保存されます。
実患者ID、患者氏名、院内機密、実メールアドレス等を入力する用途には使用しないでください。

本番運用には最低限、以下が必要です。

- 院内認証または安全なサーバー側認証
- 権限・監査ログのサーバー管理
- データベース
- 通信暗号化・バックアップ
- Microsoft 365 / Outlook 等との安全な通知連携
- 病院の情報セキュリティ審査
- AI利用時の送信データ・保存ポリシーの確定

## PDFについて

v0では委員会資料をブラウザの印刷画面に整形し、`PDFに保存` する方式です。
本番版ではサーバー側で正式PDFを生成して会議履歴に保存する想定です。
