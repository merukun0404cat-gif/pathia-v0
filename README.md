# Pathia v0.3.1（パシア）CSV直接取込版

院内クリニカルパス統合・分析支援AIシステムのGitHub Pages試作版です。

## v0.3.1の主な変更
- パスマスタは **CSVをそのまま選択して取り込み**
- 外部Excel解析ライブラリを削除し、ブラウザ標準機能だけでCSVを解析
- UTF-8 / Shift-JISを自動判定
- 対応列: CPコード / 入外区分 / 診療科 / パス項目名称 / 作成日 / 更新日
- CPコードで重複更新
- 作成中・使用停止・テスト系を「要確認」として自動判定
- 取り込み完了後、そのまま「月次登録用パスを設定」へ進める
- 病棟ごとに、取り込んだパスマスタから月次集計対象パスを選択
- 月次入力ではパス名と診療科、CPコードを自動表示
- PDFは正式登録ではなく確認待ち資料として扱うデモ
- 費用・収益CSV、議事録CSV、分析CSV出力、会議資料作成機能は継続

## ログイン
- 事務局管理者: `office`
- パスワード: `pathia0`

## パスCSVの推奨列
`CPコード,入外区分,診療科,パス項目名称,作成日,更新日`

列名が `パスコード` / `パス名` などの場合も一部自動認識します。

## テスト手順
1. `office` でログイン
2. 「データ取込」→「パスCSVをそのまま取り込む」
3. CSVを選択しプレビュー
4. 「パスマスタへ登録」
5. 完了画面で「月次登録用パスを設定」
6. 病棟と対象パスを選択
7. 月次実績・バリアンスを入力→確定
8. 事務局の月次実績管理で進捗を確認
9. 全病棟確定後「月次更新・公開」
10. 分析・会議資料の作成見本を確認

## 注意
GitHub Pages試作版です。実患者ID、実メールアドレス、院内機密は入力しないでください。
パスCSVはこの試作コードではブラウザ内で読み取りますが、本番用の認証・DB・監査・情報セキュリティ審査は未実装です。
