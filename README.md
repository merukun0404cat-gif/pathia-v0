# Pathia v0.2.4.1（パシア）

## 修正内容
- 「月次実績登録 → パスマスタから追加」で、検索・診療科の有効/無効フィルタ後にチェックしたパスを追加できない不具合を修正。
- チェックボックスが保持している元パスマスタの行番号から、表示中のパスを正しく特定して追加するよう変更。


院内クリニカルパスの統合・分析・委員会運営をイメージした GitHub Pages 向け試作版です。

## v0.2.4 追加
- パスマスタの Excel（.xlsx / .xls）取込に対応
- `2605pass.xlsx` の形式をそのまま読み込み可能
  - CPコード
  - 入外区分
  - 診療科
  - パス項目名称
  - 作成日
  - 更新日
- Excel取込時は先頭シートを使用
- CPコードが既に登録済みの場合は更新、新しいCPコードは新規登録
- 取込後は「院内パス」で検索可能
- Excel読込が利用できない環境向けに `2605pass_Pathia取込用.csv` も同梱

## GitHub Pages
1. このフォルダの中身をリポジトリ直下へアップロード
2. Settings → Pages → Deploy from a branch
3. `main` / `(root)` を選択
4. 発行URLを開く

## 注意
Excel読み込みにはブラウザ用 SheetJS を CDN から読み込みます。試作環境で CDN が遮断される場合は、同梱CSVを利用してください。本番版ではライブラリを院内配布物として同梱するか、院内サーバーへ配置する構成を想定します。

試作版のため、実患者ID・実メールアドレス・院内機密情報は入力しないでください。

## v0.2.4 追加点
- パスCSVはPathia専用CSVへ事前変換せず、そのまま取り込み可能。
- `CPコード / パスコード / コード`、`診療科 / 診療科名`、`パス項目名称 / パス名 / パス名称` など代表的な列名を自動認識。
- UTF-8系CSVに加え、文字化けが多い場合はShift-JISとして再読込を試行。
- 取り込んだパスは「院内パス」一覧へ即時反映。
- 「月次実績登録」に［＋ パスマスタから追加］を追加し、取り込んだパスを病棟ごとの当月入力対象として選択可能。
- 月次入力対象から不要なパスを当月だけ削除可能。
- パスCSV取込完了時に新規件数・更新件数を表示。

### 試し方
1. 事務局管理者 `office / pathia0` でログイン。
2. ［データ取込］→［パスCSVをそのまま取り込む］でCSVを選択し、取り込みを確定。
3. ［月次実績登録］で対象病棟を選び、［＋ パスマスタから追加］からパスを選択。
4. 実施件数・バリアンスを入力して保存／確定。
5. 事務局の［月次実績管理］で回収状況を確認し、全病棟確定後に月次更新。


## v0.2.4 追加
- 管理画面に病棟マスタを追加（追加・編集・有効/無効・月次集計対象・表示順）
- 管理画面に診療科マスタを追加（追加・編集・有効/無効・表示順）
- 無効化した病棟は新規月次入力・月次回収対象から除外し、過去実績は保持
- 無効化した診療科は新規のパスマスタ選択・院内パス一覧から除外し、過去分析は保持
- パスCSV取込時に未知の診療科を診療科マスタへ自動追加


## v0.2.4 追加
- 病棟マスタ：追加・編集・有効／無効・月次集計対象
- 診療科マスタ：追加・編集・有効／無効
- 病棟・診療科は削除ではなく無効化し、過去実績を保持
- スケジュール予定の変更・削除に対応
- 会議予定を変更／削除した場合は委員会予定も連動

## v0.3.0 追加機能
- DPC診断群分類 ↔ 自院パスの多対多紐付け
- パス検査セット（病日・標準回数・必須度）の登録／CSV取込
- 検査原価マスタの登録／CSV取込
- 自院検査実績（症例数・実施回数・削除・追加）の登録／CSV取込
- 病院ダッシュボード等のDPC診断群単位の他施設比較データ取込
- 自院平均回数 × 他施設中央値 × 原価から「見直し確認候補」を抽出
- パス係判定 → 責任医師コメント → 委員会決定の保存
- 検査見直し候補CSV出力、会議資料見本・印刷

### 重要
他施設のパス名は比較キーにしません。DPC診断群分類を比較軸とします。Pathiaは検査の医学的な不要判定をせず、確認候補の抽出に限定します。GitHub Pages試作版には実患者情報・院内機密を入れないでください。
