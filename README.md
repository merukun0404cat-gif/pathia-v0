# Pathia v0.2（パシア）

院内クリニカルパス統合・分析支援AIシステムのGitHub Pages試作版です。

## v0.2追加機能
- CSV取込期間（開始月／終了月）
- 取込確定後「取り込みが完了しました」表示と取込履歴
- 月次更新完了画面
- CSV取り出し（分析・バリアンス・パス一覧・費用収益）
- パス内容CSV取込／PDF取込候補（PDFは確認前提のデモ）
- 費用・収益CSV取込と費用対効果・収益分析デモ
- 会議資料作成見本、印刷／PDF保存
- 編集可能なクリニカルパス委員会レジュメ
- サンプル `sample-path-master.csv` / `sample-cost-revenue.csv` 同梱

## ログイン
- 事務局管理者: `office`
- パスワード: `pathia0`

## 注意
GitHub Pages試作版です。実患者ID・実メールアドレス・院内機密は入力しないでください。
PDFの自動解析・OCRはv0.2では未接続です。本番化時は院内承認済み環境で、抽出結果を人が確認してから登録する設計を想定します。
